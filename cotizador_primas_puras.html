📐 Fórmulas Actuariales
Funciones de Conmutación
D(x) = vx · l(x)
C(x) = vx+1 · d(x)
M(x) = Σ C(t), t ≥ x
N(x) = Σ D(t), t ≥ x
v = 1/(1+i) [factor de descuento]
Valores Actuariales Presentes
Ax = M(x)/D(x) [ordinario]
A1x:n̈ = (M(x)−M(x+n))/D(x) [temporario]
Ax:n̈ = (M(x)−M(x+n)+D(x+n))/D(x) [dotal]
äx = N(x)/D(x) [renta vitalicia]
äx:n = (N(x)−N(x+n))/D(x) [renta temporal]
Primas Netas Anuales (capital C)
P(Ax) = Ax·C / äx
P(A1) = A1x:n·C / äx:n
P(Ax:n) = Ax:n·C / äx:n
PU_renta = äx·R [prima única]
P_renta = äx·R / äx:n [anual n años]
Modelo MMD — Ajuste Personalizado
log μMMD(x|θ) = log μbase(x)
   + αregión
   + βsal·Δsal + βinf·Δinf
   + log HR(x, grupo_riesgo)
   + δ·(t − t₀)
